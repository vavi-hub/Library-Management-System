# Library-Management-System
A Python-based Library Management System built using Object-Oriented Programming (OOP) concepts. The project models library operations, including book management, member registration, book borrowing and returning, loan tracking, and overdue fine calculation.

The project is designed to demonstrate Python classes, inheritance, encapsulation, abstraction, polymorphism, properties, and special methods.

# Technologies Used

* Language: Python 3
* Concepts: Object-Oriented Programming
* Standard Libraries:
  * abc — Abstract base classes
  * datetime — Dates and loan periods

No third-party Python packages are required by the current implementation.
